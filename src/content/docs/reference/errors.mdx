Every error response from the standard envelope has this shape:

```json
{
  "success": false,
  "message": "Human-readable summary",
  "code": "SOME_ERROR_CODE",
  "statusCode": 400,
  "errors": {},
  "meta": { "timestamp": "2026-07-29T12:00:00.000Z", "location": "..." }
}
```

`code` is a specific, upper-snake-case identifier (for example `TENANT_CONTEXT_REQUIRED`, `STORE_NOT_FOUND`) — check the [API reference](/api/) for the specific codes each endpoint can return.

<Aside type="note">
Two surfaces don't use this envelope:

- **OAuth** (`/oauth/*`) returns raw RFC 6749-shape errors (`{"error": "...", "error_description": "..."}`) — see the [API reference](/api/) OAuth section for details.
- **Partner integrations** (`/partner/*`) nest the same fields under an `error` object: `{"success": false, "error": {"code": "...", "message": "...", "statusCode": 404}}`. See [Partner integration setup](/integrations-platform-setup/partner-integrations/partner-integration-setup/#error-responses).
</Aside>

## Status codes

| Status | Meaning |
| --- | --- |
| `200` | OK. The request succeeded. |
| `201` | Created. A new resource was created. |
| `400` | Bad Request — validation failure, missing required field, or invalid state transition. |
| `401` | Unauthorized — missing, invalid, or expired credentials. |
| `403` | Forbidden — authenticated, but lacking the required role/permission. |
| `404` | Not Found. |
| `409` | Conflict — for example an email or identifier that's already taken. |
| `422` | Unprocessable Entity — the request body or query failed schema validation. |
| `429` | Too Many Requests — you've exceeded a rate limit. Read the `RateLimit-*` response headers. |
| `500` | Internal Server Error. |
| `502` | Upstream service unavailable (for example the Cube.js analytics sidecar, or a third-party integration). |
| `503` | The requested data or feature isn't ready yet (for example pre-aggregations still warming up), or the endpoint is temporarily unavailable. |

## Common error codes seen across the API

| `code` | When you'll see it |
| --- | --- |
| `TENANT_CONTEXT_REQUIRED` | An `X-Tenant-ID` header (or equivalent) was required but missing. |
| `*_NOT_FOUND` | The requested resource ID doesn't exist, or you don't have access to it. |
| `INVALID_*` | A query or body field failed validation. |
| `CUBE_UNAVAILABLE` | The analytics data service is briefly unreachable — retry shortly. |
| `PREAGG_WARMING` | The requested data's pre-aggregations are still building. |
| `FORBIDDEN_TOKEN_TYPE` | The wrong kind of token was used for this endpoint (for example an OAuth-issued token on an endpoint expecting a normal session token). |

This isn't an exhaustive list — many endpoints have domain-specific codes (for example `EMAIL_TAKEN`, `DEFAULT_STORE_DELETION`, `SUPERMETRICS_CONNECT_DISABLED`). Check the individual endpoint's page in the [API reference](/api/) for the specific codes it can return.
