After you complete the basic onboarding, review the remaining fields in the form and how to use them. The Measurement ID and API Secret are already filled in during the basic onboarding, so this guide skips those two fields.

## Debug Mode

Enable this option if you want to send test events to validate the connection.

To view the events in the Google Analytics dashboard:

<Steps>

1. Click **Admin** (the gear icon) in the bottom left.
2. Select **DebugView** under the **Data display** section.
3. Trigger some events. The events appear in the list. You can also view the payloads of the events.

</Steps>

Disable DebugView once you are ready to send actual events.

## Skip Consent

When you enable Skip Consent, EdgeTag does not set the Google consent states. You handle Google consent yourself. This option helps if you also manage Google integration in another place, so that EdgeTag and the other source do not both initialize and update Google consent states, which can result in incorrect consent data.
