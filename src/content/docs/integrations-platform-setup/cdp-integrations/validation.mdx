## Payload validation

To enable automated payload validation while you add support for Out of the Blue.ai to your site, add a Payload Validator channel to perform these checks automatically.

### Payload Validator

This channel helps you validate event payloads sent by your site. This is especially helpful when you develop a headless website where you send events using our browser SDK or call the CDN endpoint directly using POST requests.

The channel reports all payload validation errors in the Analytics section of your site within the EdgeTag app, which helps you identify which event payloads are problematic and might be causing problems.

### Details

Channel name: `validation`
