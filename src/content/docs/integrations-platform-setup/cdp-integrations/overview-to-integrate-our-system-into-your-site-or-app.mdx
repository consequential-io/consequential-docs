Consequential offers several methods to integrate the system into your site or app.

## Apps

The Consequential app, designed for specific platforms, reduces your workload by capturing as much first-party information as possible out of the box.

### Shopify

Setting up Shopify is quick because Consequential creates an app for you. This app handles all the event coding, so you don't need coding knowledge to get started.

To get started, you need:

- Access to your DNS provider (where you host name servers).
- Permission to install a paid app in Shopify.

Setting up WordPress is quick, as Consequential provides a dedicated app for you. This app manages the `pageView` event, and if you have WooCommerce installed, it automatically captures all eCommerce events. To track more events, refer to the guide on how to send additional events.

To begin, you must have a Consequential account and a website added to it. If you haven't added your website yet, check the Getting Started guide.

## JavaScript

If your platform isn't supported out of the box, Consequential offers two methods for implementing with JavaScript.

- If your platform allows you to add code snippets to the site (commonly referred to as head snippets or HTML injection), it provides all the options available for adding a snippet and capturing data. Check the Key Concepts page before you start to understand the thinking and best practices.
- If you have developed your own front end using frameworks like React, Angular, or Next.js, you can use the NPM package suite for end-to-end integration. Check the Headless guide. It provides all the options available for adding a snippet and capturing data. Check the Key Concepts page before you start to understand the thinking and best practices.

## API

In some situations, you want to send events directly through an HTTP request. This typically happens for offline conversions or delayed processing. Check the HTTP guide on how to send the data.
