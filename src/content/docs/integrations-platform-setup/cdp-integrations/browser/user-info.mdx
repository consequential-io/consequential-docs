---
title: User info
description: Capture user information into your EdgeTag ID graph using the user and data methods.
---

User information is essential for attribution channels, so it's crucial to capture it as early as possible. This information lives in your dedicated ID graph, where, in addition to personally identifiable information (PII), EdgeTag also stores click IDs and any custom data you want to include.

EdgeTag has two ways of sending user info:

- `user`: Used for a single property, and it only accepts standard keys.
- `data`: Saves multiple properties simultaneously, including custom and standard keys.

Start by examining what the standard keys look like.
