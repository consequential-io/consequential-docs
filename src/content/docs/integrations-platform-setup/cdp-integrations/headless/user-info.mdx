---
title: User info
description: Capture user information into your EdgeTag ID graph using the user and data methods.
---

User information is essential for attribution channels, so capture it as early as possible. EdgeTag stores this information in your dedicated ID graph, where, in addition to personally identifiable information (PII), it also stores click IDs and any custom data you want to include.

You have two ways to send user info:

- `user`: Used for a single property. It only accepts standard keys.
- `data`: Saves multiple properties simultaneously, including custom and standard keys.

Start by examining what the standard keys look like.
