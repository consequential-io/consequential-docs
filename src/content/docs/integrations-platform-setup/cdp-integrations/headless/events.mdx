title: Events
description: Send standard events to different channels with the EdgeTag headless SDK tag function.
---

Sending events to different channels is straightforward with EdgeTag. Events can be anything: clicking a button, submitting a form, typing in an input, loading a page, hovering over text, and more.

To support multiple channels without requiring you to manage the payloads and the specific needs of each channel, Consequential created [standard events](https://docs.edgetag.io/overview/standard-events). This approach precisely identifies the data the platform receives and how to transform it in real time before sending it to its final destinations.

## Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | String | Yes | Name of the event that you are capturing. |
| `data` | `Record<string, any>` | No | Additional data that you want to send as part of the event. |
| `providers` | `Record<string, boolean>` | No | Define which providers you want to send this event to. By default, EdgeTag sends to all of them. |
| `options` | `{ method?: 'beacon', sync?: true, destination?: string }` | No | See [Options](#options) in the following section. |

## Options

- **Method:** If you provide the method with a value of `beacon`, EdgeTag sends this event through a beacon delivery mechanism instead of a regular fetch.
- **Sync:** Setting `sync` to `true` causes the request to wait for all channels to complete their actions before responding. This may lead to more canceled events in browsers, as some channels might need more time to respond.
- **Destination:** Specify the destination, especially if multiple EdgeTag instances exist on the website. If you don't, EdgeTag triggers the same event to multiple destinations. The destination value is the EdgeTag URL.

## Examples

Simple `PageView`:

```javascript
import { tag } from '@blotoutio/edgetag-sdk-js'

tag('PageView')
```

`AddToCart` with a payload:

```javascript
import { tag } from '@blotoutio/edgetag-sdk-js'

tag('AddToCart', { value: 10.0, currency: 'USD' })
```

`PageView` that you only want to send to the Meta channel:

```javascript
import { tag } from '@blotoutio/edgetag-sdk-js'

tag('PageView', {}, { facebook: true })
```

`PageView` where you define which destination it sends to:

```javascript
import { tag } from '@blotoutio/edgetag-sdk-js'

tag('PageView', {}, {}, { destination: 'https://d.domain.com' })
```
