The OTB MCP Gateway connects your AI assistant (Claude) to your business data, so you can run natural language queries against your metrics.

## Getting started

### Prerequisites

- Claude Desktop or Claude Code with MCP support
- An Out of the Blue account (your login credentials; no API key needed)

## Configuration

### Claude Desktop / Claude.ai

<Steps>

1. Click the Customize icon in the toolbar.
2. Go to Connectors.
3. Click Add custom connector.
4. Fill in the form:
   - Name: Out of the Blue (or anything you like)
   - Remote MCP server URL: `https://mcp.outoftheblue.ai/mcp`
   - Leave OAuth Client ID and Secret blank
5. Click Add.

</Steps>

### Claude Code (CLI)

Run the following command:

```bash
claude mcp add otb --transport http https://mcp.outoftheblue.ai/mcp
```

## First-time login

When you add the connector, Claude prompts you to authenticate:

<Steps>

1. A browser window opens automatically to `https://app.outoftheblue.ai/login`.
2. Log in with your Out of the Blue credentials.
3. You see "Authentication Successful — you can close this window".
4. Return to Claude. You are now connected.

</Steps>

Your session stays active, so you don't have to log in again unless your session expires.

## Querying your data

### Ask questions in natural language

Ask questions about your business:

- What were my total sales last week?
- Show me daily revenue for November 2024, broken down by data source.
- Which ad campaigns had the best ROAS this month?
- Compare new vs returning customer revenue for the past 30 days.

### Tips for best results

- Be specific about date ranges: "last week", "November 2024", "past 30 days".
- Mention the metric type: "revenue", "orders", "ad spend", "sessions".
- Ask for comparisons: "compare", "vs", "broken down by".
- Request visualizations: "show me a chart", "create a table".
- Verify assumptions: Claude states any assumptions made during analysis.

## Troubleshooting

### Issue 1: Browser doesn't open for login / OAuth prompt doesn't appear

**Symptom:** After you add the connector, no browser window opens and Claude can't authenticate.

Steps:

- Make sure you run the latest version of Claude Desktop or Claude Code.
- Start a new conversation. The OAuth prompt appears on first tool use.
- If you use Claude Code, run `claude mcp list` to confirm the server is registered.
- Check that your firewall or browser doesn't block `https://mcp.outoftheblue.ai`.

### Issue 2: Stuck on login page / redirected to dashboard instead of Claude

**Symptom:** After you log in, you land on the Out of the Blue dashboard instead of being redirected back to Claude.

**Cause:** The OAuth callback to Claude's local listener didn't complete, usually due to a slow or timed-out redirect.

Fix:

- Close the browser tab.
- In Claude, try again. A new OAuth flow starts.
- After "Authentication Successful — you can close this window" appears, return to Claude immediately.

If it keeps happening, try a different browser or disable extensions that may block `http://127.0.0.1` redirects.

### Issue 3: "Authentication Successful" appears but Claude still not connected

**Symptom:** The success page shows, but Claude still reports the server as disconnected.

Fix:

- Wait a few seconds. The token exchange can take a moment.
- Start a new conversation in Claude.
- If still disconnected, remove and re-add the connector and log in again.

For Claude Code:

```bash
claude mcp remove otb
claude mcp add otb --transport http https://mcp.outoftheblue.ai/mcp
```

### Issue 4: "No data returned" or unexpected results

- Check that your date range contains data.
- Ask Claude to show the query it ran: "Show me the SQL you executed".
- Verify you ask about a metric your store has data for.

## Collecting diagnostic logs

If none of the above helps, collect logs and send them to [support@outoftheblue.ai](mailto:support@outoftheblue.ai).

### Mac

| File | Location |
|------|----------|
| `mcp.log` | `~/Library/Logs/Claude/` |
| `mcp-server-otb-gateway.log` | `~/Library/Logs/Claude/` |

To access: Open Finder, go to the Go menu, hold Option (⌥), click Library, then go to Logs and Claude.

### Windows

| File | Location |
|------|----------|
| `mcp.log` | `%APPDATA%\Claude\logs\` |
| `mcp-server-otb-gateway.log` | `%APPDATA%\Claude\logs\` |

To access: Press Win + R, type `%APPDATA%\Claude\logs`, then press Enter.
