Consequential turns the data from your store, ad platforms, and analytics tools into spend alerts and performance grades. The **Integrations** page in Settings is where you review every data source connected to your workspace and connect new ones yourself.

This guide shows you how to open the Integrations page, connect a data source, manage the accounts a source syncs, spot a source that has stopped delivering fresh data, and disconnect a source.

## Prerequisites

- Access to your Consequential account with a store selected in the sidebar store switcher. New connections attach to the active store.
- The **Manager**, **Admin**, or **Owner** role to view the page. Only **Admin** and **Owner** can connect or disconnect sources. Other roles see a read-only view.

<Aside type="note">
The Consequential team labels some sources as **Coming soon** and sets these up for you, so you don't need to take any action.
</Aside>

## Open the Integrations page

<Steps>

1. In Consequential, open **Settings** from the sidebar.
2. Select the **Integrations** tab. The **Data sources** section lists every source that feeds this workspace's metrics.

</Steps>

Each source shows its name, a status badge, and — once connected — the account it's linked to and the date it was connected.

### Connection statuses

| Status | What it means |
| --- | --- |
| **Connected** | The source's credentials are linked and Consequential is set up to sync it. |
| **Disconnected** | The source was connected before but is no longer syncing. Reconnect it to resume. |
| **Available** | The source is ready for you to connect. |
| **Coming soon** | The Consequential team sets this source up for you. |

<Aside type="caution">
A **Connected** status confirms only that the credentials are linked — it doesn't guarantee the source is still delivering fresh data. A source can keep the **Connected** badge while it quietly stops sending new data (for example, after an expired token or a change on the source's side). To catch this, check data freshness and the status badge. See [Spot a source that stopped updating](#spot-a-source-that-stopped-updating).
</Aside>

## Connect a Shopify store

Shopify connects through a hosted approval flow on Shopify's side.

<Steps>

1. Find your Shopify store in the **Data sources** list and click **Connect**.
2. In the **Connect Shopify** dialog, enter your store domain, for example `acme.myshopify.com`.
3. Click **Continue to Shopify**. Consequential sends you to Shopify to approve access.
4. Approve the connection on Shopify. You return to the Integrations page and the store's status changes to **Connected**.

</Steps>

<Aside type="note">
Connecting attaches the store to the store selected in your sidebar switcher. If you manage more than one store, confirm the correct store is active before you connect.
</Aside>

## Connect an ads, analytics, or email source

Ad platforms, analytics tools, and email sources connect through Supermetrics in a popup window.

<Steps>

1. Find the source in the **Data sources** list and click **Connect**. A Supermetrics sign-in window opens.
2. Sign in to the source and approve access. When the window closes, the source's status changes to **Connected**.
3. In the **accounts** dialog that opens, select the accounts you want Consequential to sync, then confirm your selection.

</Steps>

If the connection window expires before you finish, the source stays unconnected. Click **Connect** to start again.

## Manage the accounts a source syncs

For a connected ads, analytics, or email source, you can change which accounts Consequential syncs at any time.

<Steps>

1. Find the connected source in the **Data sources** list.
2. Click **Accounts**.
3. Update your selection in the dialog, then confirm.

</Steps>

## Reconnect a source

A source with a **Disconnected** status is no longer syncing. To resume it, click **Reconnect** and follow the same steps as the first connection.

## Spot a source that stopped updating

A source can stay **Connected** yet stop delivering new data — for example, when an access token expires or the source changes something on its side. When that happens, the connection status still reads **Connected**, so you must check data freshness to catch it.

Consequential flags a source as stopped when both of these are true:

- A metric that depends on the source returns no data for the period you're viewing.
- The source's most recent data is several days old — well past the normal daily refresh. (Sources refresh once a day, so a source being a day or two behind is expected, and Consequential stays quiet.)

When Consequential detects this, the affected metric card shows the message *"This source stopped updating on \<date\>"* — where the date is the last day the source delivered data — instead of the usual *"No data for this period."* The two messages mean different things:

| Message on a metric card | What it means |
| --- | --- |
| *No data for this period* | The source is current, but it has no data for the dates you selected. Try a wider date range. |
| *This source stopped updating on \<date\>* | The source hasn't delivered new data since that date. Follow the steps below. |

<Aside type="note">
This message appears on metric cards on your Home page and metrics pages. Other surfaces, such as the Acquisition Dashboard and daily reports, may show an empty state without this message. If metrics look empty across several surfaces, check the source's freshness here first.
</Aside>

To resolve a source that stopped updating:

<Steps>

1. Open the **Integrations** page and find the source named in the affected metrics.
2. If its status is **Disconnected**, click **Reconnect** and complete the connection again.
3. If its status is still **Connected**, its stored credentials may have expired or been revoked on the source's side. Click **Reconnect** to re-authorize the source with fresh credentials.
4. After you reconnect, allow up to a day for the next scheduled sync to bring the data current.

</Steps>

<Aside type="tip">
If a source keeps stopping after you reconnect it, or data doesn't return after the next daily sync, contact the Consequential Support Team at [support@outoftheblue.ai](mailto:support@outoftheblue.ai) with the source name and the date shown in the message.
</Aside>

## Disconnect a source

<Steps>

1. Find the connected source in the **Data sources** list.
2. Click **Disconnect**.
3. Confirm in the dialog.

</Steps>

Disconnecting revokes Consequential's stored credentials for the source and pauses its data sync. Metrics that depend on the source stop updating until you reconnect it.

<Aside type="caution">
Disconnecting stops new data from flowing in. Reconnect the source to resume syncing.
</Aside>
