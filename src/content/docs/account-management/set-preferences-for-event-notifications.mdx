## Setting preferences for alerts

Navigate to **Account Settings** and click **Preferences**. Under **Preferences**, go to **Notifications**. Click the gear icon to configure event providers and event type settings. Here, view the list of providers by expanding each provider.

Set which types of errors you want to receive alerts for. For example:

- For Facebook: notify about authorization and payload errors.
- For Twitter: don't notify about any errors currently.

Once you have chosen providers and associated categories you want to be informed about, click **Save Changes**.

## Defining minimum impact for alerts

Set a dollar impact threshold to define the minimum dollar impact an error must have on your business before you receive a notification. For example, set it to be alerted only for events impacting over $10,000.

## Managing alert channels

To receive alerts via email, toggle the email/SMS option on or off.
