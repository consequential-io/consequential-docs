A **daily report** is an AI-generated summary of your store's performance for a
single day. Each morning, Consequential analyzes the previous day's metrics
against your recent history, flags the movements that matter, and explains them
in plain language — so you start the day knowing what changed and why, without
building a single query.

This guide shows you how to find your reports, read each section, regenerate a
report on demand, and customize the prompts that shape how reports read.

## Where to find your reports

Open the **Reports** tab in the navigation sidebar. The Reports page lists your most
recent daily reports, newest first, each labeled with its date and current
status. Select a date to open the full report.

A new report generates automatically every morning for the previous day. You
don't need to request it — when you open the Reports tab, the latest report is
ready to read.

<Aside type="note">
	Reports cover whole calendar days in your store's time zone. The most recent
	report is always for yesterday, since a full day of data is needed before a
	report can be built.
</Aside>

## Read a report

A report is organized into blocks, ordered from the highest-level summary down to
the supporting detail. The report hides empty sections, so every report shows only what
is relevant for that day.

| Block | What it shows |
|-------|---------------|
| **Summary** | A short narrative at the top of the report describing the day's most important changes. |
| **Notable movers** | The metrics with the largest, most statistically significant swings, shown as cards with the current value, the change versus the comparison period, and a flag on unusually large moves. |
| **Callouts** | Issues and opportunities worth your attention, each with a severity of high, medium, or low and a short explanation. |
| **Drilldowns** | A breakdown of a notable metric by dimension — for example, which campaigns or channels drove a change — with a narrative explaining the breakdown. |
| **Context** | Business context that helps explain the day's numbers, drawn from your marketing campaigns, funnel events, product mix, and saved annotations. |
| **All metrics** | A collapsible grid with every tracked metric for the day, for when you want the full picture. |

Every number in a report comes directly from your data. The AI describes and
prioritizes what it finds, but it doesn't invent or estimate values.

### Report status

A report moves through several states as it is built. The Reports tab shows the
current status for each date:

| Status | Meaning |
|--------|---------|
| **Generating** | The report is being built. Check back shortly. |
| **Ready** | The report is complete and ready to read. |
| **No baseline** | There isn't enough comparable history yet to build a report for this date. |
| **Failed** | Generation ran into an error. Regenerate the report to try again. |

<Aside type="note">
	A **No baseline** status is normal for new stores and for metrics with
	little history. As Consequential collects more days of data, reports fill in
	automatically.
</Aside>

## Regenerate a report

If a report failed, or you want to rebuild it after correcting your data, you can
generate it again.

<Steps>

1. Open the report for the date you want to rebuild.

2. Select **Regenerate**.

3. Wait for the status to return to **Ready**. Regenerating replaces the existing
   report for that date with a fresh one.

</Steps>

<Aside type="caution">
	Regenerating is available to workspace owners and admins. It replaces the
	current report for that date, so the previous version isn't kept.
</Aside>

## Customize report prompts

Reports are generated from a set of editable **prompts** — the instructions that
tell the AI how to structure the report, which details to drill into, and how to
write the narrative. Owners and admins can tailor these prompts so reports match
your team's voice and priorities.

To edit prompts, open **Settings** and select **Report prompts**.

### How prompts are organized

Your reports are produced in three passes, and you can edit the prompt for each:

- **Structure** — decides which metrics and callouts appear in the report.
- **Drill** — decides which movements to break down by dimension.
- **Narrative** — writes the summary and callout text.

Each pass has a system prompt and a user prompt. Prompts can include
placeholders, written as `{{variable}}`, that Consequential fills in with your
data and brand guidelines when the report runs. Keep the placeholders that a
prompt requires — Consequential checks for them before you can publish.

### Edit, publish, and version

Your workspace starts on the shared global default prompts. The first time you
customize, Consequential clones the current defaults into a draft for your
workspace, so you always edit from a working starting point rather than a blank
page.

<Steps>

1. On the **Report prompts** page, select **Customize for my tenant**. This
   creates a draft from the active prompts.

2. Edit any of the three passes. Consequential highlights a prompt if a required
   `{{variable}}` placeholder is missing.

3. Select **Save draft** to keep your edits without affecting live reports.

4. When you're ready, select **Publish**. Publishing validates your prompts,
   assigns the next version number, and makes the prompts live for future
   reports.

</Steps>

Every published version is kept. The **Version history** section lists each
version with its number and the time it was last updated, and marks the version
that's currently active. To roll back, select **Activate** on an earlier
version — this makes it live again without creating a new version.

<Aside type="note">
	Each report records the prompt version that produced it, so you can always
	trace a report back to the exact prompts that shaped it. Changing prompts
	affects future reports only; existing reports are unchanged.
</Aside>

## For developers

The Reports tab is backed by a REST API scoped to your workspace (tenant).
Reading reports is available to any workspace member; regenerating reports and
editing prompts require the owner or admin role.

| Method & path | Purpose |
|---------------|---------|
| `GET /api/v1/tenants/:tenantId/reports` | List recent daily reports. |
| `GET /api/v1/tenants/:tenantId/reports/:date` | Fetch a single report by `YYYY-MM-DD` date. |
| `POST /api/v1/tenants/:tenantId/reports/:date/regenerate` | Rebuild the report for a date. |
| `GET /api/v1/tenants/:tenantId/prompt-sets` | List prompt versions for your workspace. |
| `POST /api/v1/tenants/:tenantId/prompt-sets/draft` | Create or fetch the working draft. |
| `PUT /api/v1/tenants/:tenantId/prompt-sets/draft` | Save edits to the draft. |
| `POST /api/v1/tenants/:tenantId/prompt-sets/draft/publish` | Publish the draft as a new version. |
| `POST /api/v1/tenants/:tenantId/prompt-sets/:versionId/activate` | Activate an existing version. |
