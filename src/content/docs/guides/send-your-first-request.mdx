This guide demonstrates a complete read against the real Consequential API:
list a tenant's daily reports, then fetch one report by date.

<Aside>
	A **how-to guide** assumes the reader already knows the basics. If you're
	new, start with **[Get started](/get-started/overview/)** first.
</Aside>

## Steps

<Steps>

1. **Get a Bearer JWT.** Sign in to the app, then follow
   [Create API keys](/how-tos/onboarding/create-api-keys/) to obtain a token,
   and note your tenant's UUID (shown in Settings).

2. **List recent daily reports.**

   <Tabs syncKey="lang">
     <TabItem label="curl">
       ```bash
       curl https://api.consequential.io/tenants/$TENANT_ID/reports \
         -H "Authorization: Bearer $TOKEN" \
         -H "X-Tenant-ID: $TENANT_ID"
       ```
     </TabItem>
     <TabItem label="JavaScript">
       ```js
       const reports = await fetch(
         `https://api.consequential.io/tenants/${tenantId}/reports`,
         {
           headers: {
             Authorization: `Bearer ${process.env.TOKEN}`,
             'X-Tenant-ID': tenantId,
           },
         },
       ).then((r) => r.json());
       ```
     </TabItem>
   </Tabs>

   Each item includes a `reportDate` and a `status` (`pending`,
   `snapshotting`, `generating`, `ready`, `failed`, or `no_baseline`). Note a
   `reportDate` with status `ready` for the next step.

3. **Read that report back.**

   <Tabs syncKey="lang">
     <TabItem label="curl">
       ```bash
       curl https://api.consequential.io/tenants/$TENANT_ID/reports/$REPORT_DATE \
         -H "Authorization: Bearer $TOKEN" \
         -H "X-Tenant-ID: $TENANT_ID"
       ```
     </TabItem>
     <TabItem label="JavaScript">
       ```js
       const report = await fetch(
         `https://api.consequential.io/tenants/${tenantId}/reports/${reportDate}`,
         {
           headers: {
             Authorization: `Bearer ${process.env.TOKEN}`,
             'X-Tenant-ID': tenantId,
           },
         },
       ).then((r) => r.json());
       ```
     </TabItem>
   </Tabs>

   The response's `data.html` field is the same rendered report your team
   receives by email.

</Steps>

<Aside type="caution">
	Regenerating a report on demand isn't available yet — see the
	[Daily reports guide](/guides/daily-reports/) for why, and what to do
	instead.
</Aside>
