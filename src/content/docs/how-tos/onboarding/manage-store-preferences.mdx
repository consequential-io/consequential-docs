import { Steps } from '@astrojs/starlight/components';

## Set up store preference

<Steps>

1. Log in to your account.
2. In the top right corner menu, click **Account Settings**.
3. Click **Store Preference**.

</Steps>

## Update or change the store preference

<Steps>

1. Open your web browser and go to [app.consequential.io](https://app.consequential.io).
2. In the top right corner, find the **Store** option.
3. Select the dropdown option and update it according to the location.

</Steps>
