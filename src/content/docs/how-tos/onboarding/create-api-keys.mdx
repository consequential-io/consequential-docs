import { Steps } from '@astrojs/starlight/components';

API keys in Out of the Blue let you securely connect and integrate external applications with the platform. These keys enable automated data transfers, ensuring communication between systems while maintaining security and control over access.

<Steps>

1. Go to [outoftheblue.ai](https://outoftheblue.ai).
2. Click the **Login** button.
3. Navigate to **Account Settings** and select **Preferences**.
4. Click **API Keys**.
5. Select **Generate API Key**. A pop-up window appears.

</Steps>
