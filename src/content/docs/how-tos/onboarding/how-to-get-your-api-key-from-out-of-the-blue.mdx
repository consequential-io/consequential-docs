API keys let you securely integrate Out of the Blue with external platforms, tools, or custom scripts. This guide walks you through generating your key.

{/* This article references a video walkthrough that shows the entire process in under 1 minute. */}

## Step-by-step instructions

<Steps>

1. Log in to Out of the Blue. Go to [https://app.outoftheblue.ai/login](https://app.outoftheblue.ai/login) and log in with your credentials.
2. Click **Settings** in the bottom-left corner.
3. Open the API key tab. In the left sidebar, click **API & Integrations**, then choose the **API Keys** section.
4. Click **+ Generate API Key**.
5. Name your key (for example, "Zapier Sync" or "CRM Integration").
6. Copy your key immediately and store it securely. It's also accessible in the UI for future reference.

</Steps>

<Aside type="caution">
Treat your API key like a password. Anyone with this key can access your data.
</Aside>

## Keep in mind

- You can revoke or regenerate keys at any time.
- If you suspect a compromise, delete the key and issue a new one.
- Follow your organization's security protocols for managing API credentials.
