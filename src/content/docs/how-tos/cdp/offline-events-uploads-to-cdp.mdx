---
title: Offline Events Uploads to CDP
description: Upload offline Lead, Purchase, and PageView event data to the CDP using CSV files.
---

You can upload the following offline event data:

- Lead
- Purchase
- PageView

## File criteria

- Only CSV files are accepted.
- Maximum 1000 rows (excluding the header).
- Either email or phone is required for Lead and Purchase events. `page_url` is required for PageView.
- Additional params are optional.
