## Introduction

When installed on your storefront, the Out of the Blue Pulse JavaScript SDK monitors the following:

- Any website errors occurring on the BigCommerce store.
- Standard customer events that help you track drops or spikes, including:
  - Page views
  - Product views
  - Product added to cart
  - Checkout started
  - Shipping info submitted
  - Payment info submitted
  - Checkout completed

To track these events, OutOfTheBlue provides two HTML script URLs that you configure in your BigCommerce storefront.

## OutOfTheBlue Events Tag ID

When you sign up with OutOfTheBlue, the platform creates a default store view where you can see the events occurring on your default store. You can also configure multiple stores with OutOfTheBlue.

<Aside type="note">
For BigCommerce, OutOfTheBlue currently supports self-serve onboarding of only one store. To onboard multiple BigCommerce stores, contact `connect@outoftheblue.ai`.
</Aside>

With each store created on the platform, OutOfTheBlue creates a tag identifier called `otb_events_tag_id`. This Tag ID is unique to each store. You receive your Tag ID when you sign up with Out of the Blue.

## Configure OutOfTheBlue Pulse error script URL

Follow these steps to enable the Pulse error script on your BigCommerce store:

<Steps>

1. Log in to your BigCommerce Store Admin.
2. Click **Storefront**.
3. In **Storefront**, click **Scripts Manager**.
4. Click **Create a script**.
5. Enter a script name and description.
6. Set **Placement** to **Header**.
7. Set **Location** to **All Pages**.
8. Set **Script Category** to **Essential**.
9. Set **Script Type** to **URL**.
10. Set **Load Method** to **Async**. This is important.
11. Paste the error script URL provided to you by the OutOfTheBlue Customer Success team.

</Steps>

The script URL uses the following format:

```text
https://cdn.outoftheblue.ai/big_commerce/events/customer_events.min.js?otb_events_tag_id=OTB-250102-AE534
```

The platform provides these URLs to you.

## Configure OutOfTheBlue Pulse customer events script URL

Follow the steps for configuring the error script above to configure the customer events script on your BigCommerce store. On the Create Script page, set the following details:

- Enter a script name and description.
- Set **Placement** to **Header**.
- Set **Location** to **All Pages**.
- Set **Script Category** to **Analytics**.

You can capture customer events in one of two ways, depending on your store's implementation:

- Enable capturing customer events using the TagRocket API.
- Enable capturing customer events using BODL.

### Enable capturing customer events using the TagRocket API

TagRocket contains data and event-gathering capabilities, but it does not support every tag out of the box. TagRocket enables enhanced tagging for unsupported tags through an API.

<Steps>

1. Install the TagRocket app from the app store. Skip this step if TagRocket is already installed.
2. Switch to the **Dashboard**.
3. Scroll down and select **Settings** from the **Global Tag Values** section.
4. Scroll to find the **Tag Rocket API** section.
5. Check the **Fire All Events** option.
6. Click **Finish Editing** in the top right corner of the pop-up.
7. Click **Publish** or **Republish** to add TagRocket to your store.

</Steps>

To read more about the TagRocket APIs, visit the [TagRocket website](https://tagrocket.io/).

### Enable capturing customer events using BODL

<Steps>

1. Click **Settings**.
2. Click **Data Solutions**.
3. Click **show advanced setting**.
4. Select the **Turn On Data layer** checkbox.

</Steps>

This enables BigCommerce data layers, which let third-party analytics providers such as Google Analytics and OutOfTheBlue track standard customer events.
