## Introduction

The Consequential Pulse JavaScript SDK enables third-party analytics for any eCommerce store.

### Purpose

- Capture and send customer interaction data for insights and personalization.
- Track any errors occurring on your website to see whether they block the customer experience.
- Improve decision-making by tracking standard user events and errors directly from the storefront.

### Key features

- Collects standard customer events and sends them to Consequential for processing.
- Integrates with JavaScript-based frontend applications.

## Prerequisites

<Steps>

1. Sign up at [app.consequential.io](https://app.consequential.io). The sign-up process involves filling in details on a set of pages.

## Capturing errors

You don't need to do anything extra to capture errors once you inject the script. The script includes a variable named `enableErrorTracking`, which you can set to `true` or `false`. When set to `true`, the script captures errors from the website.

## Capturing customer events

The Consequential Pulse SDK exposes a method called `pulsePush()`, which sends individual events to Consequential:

```javascript
window?.pulseSDK?.pulsePush(event, event_name, "customer_event");
```

All three parameters are mandatory:

- `event`: The details object you want to send with the event. It contains key-value pairs of data generated on the specific page where the event occurs. The keys and expected values appear in the tables that follow.
- `event_name`: One of the seven events listed below. The value must match exactly, otherwise the SDK throws an error.
- `customer_event`: A string that must be passed as-is. It notifies the SDK that this is a customer event.

Invoke the method whenever a user reaches a particular page. For example, invoke `page_viewed` when a user views any page. When a user views a product, invoke both `page_viewed` and `product_viewed`. The SDK invokes the `page_viewed` event alongside every other event, while the rest occur only when they happen.

The SDK tracks the following customer events.

### page_viewed

Triggered when a user views any page. Send an empty object `{}` as the payload.

```javascript
window?.pulseSDK?.pulsePush({}, "page_viewed", "customer_event");
```

### product_viewed

Triggered when a customer views a specific product.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `currency` | string | No | The currency for the value specified. |
| `value` | number | No | A numeric value associated with this event, such as a monetary value or a value in another metric. |

```javascript
window?.pulseSDK?.pulsePush({currency: 'USD', value: 10.50}, "product_viewed", "customer_event");
```

### product_added_to_cart

Triggered when a user adds a product to the cart.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `currency` | string | Yes | The currency for the value specified. |
| `value` | number | Yes | A numeric value associated with this event, such as a monetary value or a value in another metric. |
| `page_url` | string | No | Checkout page URL. |

```javascript
window?.pulseSDK?.pulsePush({currency: 'USD', value: 10.50, page_url: 'https://mysite.com/summer-fun'}, "product_added_to_cart", "customer_event");
```

### checkout_started

Triggered when a user starts the checkout process.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `currency` | string | No | The currency for the value specified. |
| `value` | number | No | A numeric value associated with this event, such as a monetary value or a value in another metric. |
| `checkoutUrl` | string | No | URL to go to the checkout page. |

```javascript
window?.pulseSDK?.pulsePush({currency: 'USD', value: 10.50, url: 'https://mysite.com/summer-fun'}, "checkout_started", "customer_event");
```

### checkout_shipping_info_submitted

Triggered when a user fills in shipping information.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `currency` | string | No | The currency for the value specified. |
| `value` | number | No | A numeric value associated with this event, such as a monetary value or a value in another metric. |

```javascript
window?.pulseSDK?.pulsePush({currency: 'USD', value: 10.50}, "checkout_shipping_info_submitted", "customer_event");
```

### payment_info_submitted

Triggered when a user submits payment information.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `currency` | string | No | The currency for the value specified. |
| `value` | number | No | A numeric value associated with this event, such as a monetary value or a value in another metric. |

```javascript
window?.pulseSDK?.pulsePush({currency: 'USD', value: 10.50}, "payment_info_submitted", "customer_event");
```

### checkout_completed

Triggered when a user places the order.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `currency` | string | Yes | The currency for the value specified. |
| `value` | number | Yes | A numeric value associated with this event, such as a monetary value or a value in another metric. |
| `order_id` | string | Yes | The order ID for the transaction. |
| `event_id` | string | No | Event UUID of the event generated as part of this action. |

```javascript
window?.pulseSDK?.pulsePush({currency: 'USD', value: 31.00, order_id: '234234234234', event_id: '234234234234'}, "checkout_completed", "customer_event");
```
