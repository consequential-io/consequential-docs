## Introduction

The Consequential Pulse JavaScript SDK enables third-party analytics for Shopify stores with a headless setup.

### Purpose

For headless Shopify stores, the standard Shopify App Pixel cannot gather customer events. This SDK bridges that gap by enabling the collection of standard customer events in headless setups.

### Key features

- Collects standard customer events as defined in the [Shopify Web Pixels API documentation](https://shopify.dev/docs/api/web-pixels-api).
- Designed specifically for headless Shopify store architecture.
- Integrates with JavaScript-based frontend applications.

## Usage

There are two ways to push standard customer events to the Consequential Pulse SDK:

- Using the Hydrogen Analytics UI SDK.
- Placing the Pulse SDK in `onClick()` handlers (coming soon).

### Using the Hydrogen Analytics UI SDK

If the Hydrogen Analytics SDK is already installed in your frontend repository, integrating the Pulse SDK is more direct.

<Steps>

1. **Understand Hydrogen Analytics.** Refer to the [Hydrogen Analytics documentation](https://shopify.dev/docs/api/hydrogen/utilities/analytics) for background information.
2. **Add event subscriptions.** In the `useEffect()` hook, add subscriptions for the following events:
   - `page_viewed`
   - `product_viewed`
   - `product_added_to_cart`
   - `checkout_started`
   - `checkout_shipping_info_submitted`
   - `payment_info_submitted`
   - `checkout_completed`
3. **Implement the Pulse SDK** using the following example.

</Steps>

```jsx
import { useAnalytics } from '@shopify/hydrogen';
import { useEffect } from 'react';
import { pulsePush } from "@consequential/pulse";

export function ThirdPartyAnalyticsIntegration() {
  const { subscribe } = useAnalytics();
  const { ready } = register('Third Party Analytics Integration');

  useEffect(() => {
    // Standard events
    const events = [
      'page_viewed',
      'product_viewed',
      'product_added_to_cart',
      'checkout_started',
      'checkout_shipping_info_submitted',
      'payment_info_submitted',
      'checkout_completed'
    ];

    events.forEach(event => {
      subscribe(event, (data) => {
        // Push the event data to the Consequential Pulse platform.
        // Failure conditions are handled.
        window?.pulseSDK?.pulsePush(event, data, "customer_event");
      });
    });

    // Mark this analytics integration as ready
    ready();
  }, []);

  return null;
}
```

This component uses the `window?.pulseSDK?.pulsePush()` function to send data to the Consequential Pulse platform whenever a subscribed event occurs.
